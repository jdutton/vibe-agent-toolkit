# vat-example-cat-agents

Reference implementation of VAT agent archetypes (cat breeding domain).

**Local rule:** Agents are plain TypeScript functions — no framework dependencies in agent code. Runtime adapters translate agents to framework-specific formats.

For everything else — archetype status, directory layout, code patterns, running tests/demos, adding agents — see [README.md](./README.md) and [docs/structure.md](./docs/structure.md).
