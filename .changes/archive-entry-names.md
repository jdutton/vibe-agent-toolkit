### Breaking

- **An archive holding a `.git` file or folder at any depth, in any spelling a filesystem resolves to
  `.git`, is refused on every host** (`INPUT_UNREADABLE`, `unsafe-name`): extracted, it would make
  the install a git repository VAT and git act on. Remove it from the archive before packing.
- **Two archive entries, or two plugin `files:` destinations, whose names differ only by a code point
  HFS+ ignores when comparing names (zero-width joiners, direction marks, U+FEFF) are refused as one
  name**, as names differing only by case or Unicode form already were. Rename one of them.
